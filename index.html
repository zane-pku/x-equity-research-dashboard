手动更新

默认合并公开索引与可用 RSS。若需直接核对八个账号最近七天的官方时间线，可在本机配置有读取权限的 X_BEARER_TOKEN，运行 py .\update_market.py --x-api；X API 可能计费。公开模式仅显示实际归档的最新时间。

在 index.html 所在的项目目录打开 PowerShell。运行下方命令，完成后刷新网页。

py .\update_market.py

可用 py -B .\update_market.py --check 检查本地文件和归档。也可指定研究日期。

py .\update_market.py --date 2026-11-20

如已在本机配置 OpenAI API 密钥，可显式运行以下命令生成带原帖引用的研究草稿。这一步会调用付费 API。

py .\update_market.py --research

默认使用 Windows 自带 OCR，尝试识别所选日及前一日最多 6 张附件；可用 --images 扩至近 30 日、每轮最多 24 张。图表数字需要核对原图的轴、单位与图例。图片地址不可读时，可对已保存到本机的原图运行：

py .\update_market.py --image-file "截图.png" --post-id 原帖编号 --image-index 1
